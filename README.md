# マップ鍛造 — AIYA マップデザイナー

ブラウザだけで動く、アイソメ・タイルマップのエディタです。書き出した JSON はそのまま
Unity（aiya-desire）の `Assets/Adventure/Data/Maps/` に置けます。

公開 URL: https://vnl-works.github.io/aiya-map-designer/

## 2つのモード

| | 単一マップモード（従来） | 階層モード（新規） |
|---|---|---|
| 扱う単位 | 1枚の JSON | 階層まるごと（複数の部屋） |
| 入口 | 「JSON インポート」 | 右ペイン「第2階層を読み込む」または「ファイルから読み込む」 |
| 書き出し | 「JSON エクスポート」 | 「zip 書き出し」（全部屋＋`floor.json`）／「この部屋を保存」 |

タイル編集（ペイント・矩形・塗りつぶし・コピー貼付・ルール…）は両モード共通です。

## 階層モードでできること

- **部屋タブ**: 上のストリップで部屋を切替。`[` / `]` キーでも移動。undo 履歴は部屋ごと。
- **扉ツール**: ツール「扉」でセルをクリック → 接続先を選ぶ → 相手の部屋に切り替わるので戻り扉のセルをクリック。
  両側の `exit,<部屋id>` が自動で対になります。既存の扉をクリックすると「相手の扉へ／接続先変更／両側削除」。
- **タグ辞書**: 右ペイン「ポイント」の下に、その部屋で使うタグがチップで並びます。
  実線＝配置済み（クリックでその場所へ）、点線＝未配置（クリックで配置モード）、黄＝辞書に無いタグ。
- **検証**: 右ペイン「階層」に常時表示。行き先の無い扉／戻り扉の欠落／`start` の数／空セル上のポイント／
  重複タグ／到達できない部屋を検出。項目クリックでそのセルへジャンプ。部屋タブにもエラー数が出ます。
- **接続一覧**: 扉の対応表。「相手へ」で戻り扉に移動、「戻り扉」で片側だけの扉を補完。
- **オーバービュー**: ステージ右下の俯瞰図。ハブ（扉が最多の部屋）を中心に、各部屋をハブ側の扉の方角へ自動配置。
  クリックで部屋切替、ドラッグで並べ替え（位置は保存）、「拡大」で全画面。
- **保存**: 階層の状態はブラウザ（localStorage）に自動保存され、リロードしても残ります。

## データ

- `floors/stage02/` — 第2階層の現行データ（aiya-desire `Assets/Adventure/Data/Maps/stage02*.json` のコピー）と
  マニフェスト `floor.json`（部屋名・略称・ファイル名・タグ辞書）。
- 部屋 JSON の書式は Unity 側の契約どおり `{ id, size, map, points }`。無編集で書き出すと元ファイルとバイト一致します。
- `floor.json` の `tags` は `"部屋id": [{ "tag": "...", "label": "..." }]`。`"*"` は全部屋共通。

## Unity へ戻すとき

zip を展開し、部屋 JSON を `Assets/Adventure/Data/Maps/` の同名ファイルに上書き → Unity の
`Tools/Adventure` のバリデータ（T2＝扉解決）とステージ生成スモークを回してください。
ファイルは GUID で参照されているので、中身の上書きだけで配線は保たれます。

## ローカルで動かす

`fetch` を使うので `file://` では「第2階層を読み込む」が動きません。静的サーバー経由で開いてください。

```bash
python -m http.server 8765
```

→ http://localhost:8765/

## ファイル構成

- `index.html` — エディタ本体（単一マップ機能）
- `floor.js` / `floor.css` — 階層モード
- `assets/*.png` — タイル画像（番号 = タイル id）
- `floors/<階層>/` — 階層データ
